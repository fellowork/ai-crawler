# AI Crawler Files

This repository hosts configuration files for AI systems and language models that crawl and access our website content.

## Files

- **`llms.txt`** - Main configuration file following the [llms.txt standard](https://llmstxt.org/)
- Additional AI-related configuration files may be added in the future

## Purpose

This repository serves as a centralized location for:
- Providing clear guidelines to AI crawlers and LLMs
- Defining content usage policies and attribution requirements
- Offering structured information about our website and content
- Maintaining version control over AI crawler configurations

## Access

The llms.txt file is publicly accessible at:
- **GitHub Pages URL**: `https://fellowork.github.io/ai-crawler/llms.txt`
- **Main Website Reference**: Links from our primary website point here

## Updating

To update the llms.txt file:
1. Edit the file directly on GitHub
2. Or clone this repository, make changes, and push updates
3. Changes are automatically deployed via GitHub Pages

## Standard Compliance

Our llms.txt file follows the community standard outlined at [llmstxt.org](https://llmstxt.org/), ensuring compatibility with AI systems that respect these conventions.
